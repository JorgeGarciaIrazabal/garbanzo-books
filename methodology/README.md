# Methodology — the craft behind the books

These documents distill how professional studios and publishers actually make children's
picture books, and the reading science that should shape every word choice. The skills in
`.claude/skills/` operationalise these docs; read the relevant one before doing the work.

| Doc | Use it when |
|---|---|
| [storybook-pipeline.md](storybook-pipeline.md) | Planning a book: premise, spine, page count, storyboard/dummy, page-turns, production gates. |
| [reading-pedagogy.md](reading-pedagogy.md) | Choosing/age-adapting language: leveling systems, the five pillars, per-band targets, readability formulas. |
| [consistency.md](consistency.md) | Keeping characters, world, and art style coherent across many images & stories. |
| [interactivity.md](interactivity.md) | Designing puzzles, games & participation that match the age band and build reading skill. |
| [accessibility.md](accessibility.md) | Typography, contrast, dyslexia-friendly text, and legible text-on-image. |

> Numbers in these docs are **targets, not laws** — break them deliberately, and record why.
